# 📱 iPhone Calculator App

A modern iPhone-style Calculator built using **Python** and **CustomTkinter**. This project replicates the clean UI of Apple's Calculator with basic arithmetic operations and a responsive interface.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage Calculation
- ⌫ Backspace Function
- 🧹 All Clear (AC)
- 📱 iPhone-inspired User Interface
- 🎨 Custom Dark Theme
- 🔢 Double-width "0" Button Layout

---

## 🛠️ Technologies Used

- Python 3
- CustomTkinter

---

## 📂 Project Structure

```
iPhone_Calculator/
│── main.py
│── calculator.py
│── theme.py
│── requirements.txt
│── assets/
```

---

## 🚀 How to Run

1. Clone or download this repository.
2. Install the required package:

```bash
pip install customtkinter
```

3. Run the application:

```bash
python main.py
```
